# Capturas locais

Capturadas em 14/10/2026 com Chromium/Playwright, a partir do build Svelte e do
servidor FastAPI, banco PostgreSQL de testes separado e requisições HTTP reais.
São exemplos de uma demonstração fictícia, não evidência de operação comercial.

- `services.png`: registro inicial, quatro serviços sem medições; viewport 1440×1000.
- `monitor.png`: HTTP 200 seguido de duas respostas HTTP 503; viewport 1440×1000.
- `incident-mobile.png`: primeira falha, confirmação, reconhecimento e recuperação;
  viewport 390×844, captura de página inteira.

Horários e durações são os valores daquela execução local. Os registros não
foram inseridos como histórico inicial do produto. Fonte local carregada,
ausência de rolagem horizontal e análise WCAG A/AA automatizada foram conferidas
na captura. Não são mockups nem imagens geradas por IA.
